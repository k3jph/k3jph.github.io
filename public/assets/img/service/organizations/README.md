does not suggest organizational endorsement of the website.

Creative Commons credits, source links, license links, and alteration notes appear
on the corresponding service cards. The new SAR file is distributed unchanged
under CC BY-SA 4.0; the website's code and other images retain their own licenses.

Official-site Augustan, MORS, UMGC, and other marks were considered but were not
included without sufficiently clear reuse terms. No placeholder image is required
for a card without an approved asset. Unselected downloads are not committed.
